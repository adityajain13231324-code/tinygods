# Enchanted forest menu artwork

Created for Tiny Gods with the built-in image generation tool on 8 November 2026. The user-provided fantasy menu image was the style reference. The artwork is used only behind the main menu and menu dialogs; the playable town UI is unchanged.

Prompt: Create a polished 16:9 illustrated background plate for the main menu of a whimsical strategy browser game called Tiny Gods. Use the attached reference image only as visual inspiration: enchanted twilight forest clearing, deep teal and emerald color palette, softly glowing cyan mushrooms at the lower corners, ancient carved stone columns framing far left and far right, subtle gold fireflies and a few floating red blue green yellow geometric shapes, slightly luminous pathway along the bottom. Keep the central left and central right areas very dark, calm, low-detail and readable so HTML title and menu cards can be placed over them. Game art style: premium hand-painted 2D fantasy key art, warm magical atmosphere, crisp attractive lighting, sophisticated rather than childish. Background art only. Absolutely no words, letters, logo, UI, cards, buttons, panels, characters, or watermark. Landscape widescreen 16:9.

Asset: public/menu/enchanted-forest.webp (re-encoded from a 2.1 MB PNG to 163 KB). Navigation, text, and focus styles remain live HTML/CSS.
